# Beginner Books

A reader-friendly static ebook website built for GitHub Pages.

## Included books

- **Software Testing for Beginners** — 100 reading pages across 10 modules
- **English for Beginners** — 100 reading pages across 10 modules

Every page contains a beginner explanation, a practical example, a short exercise, Q&A and a mini quiz.

## Reader features

- 200 learning pages total
- Responsive mobile, iPad and laptop layout
- Module-based table of contents
- Previous/next navigation
- Search across both books
- Bookmarks
- Per-page completion tracking
- Saved progress using localStorage
- Small/medium/large font controls
- Paper, light and dark reading themes
- Print-friendly styling

## GitHub Pages

This repository includes `.github/workflows/pages.yml`. Set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. Every push to `main` will then publish the site.

Expected project URL for this repository: `https://vsj91.github.io/ebooks/`
